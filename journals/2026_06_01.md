		- [Liveline](https://benji.org/liveline) 是一个面向 React 的实时动画折线图组件：只依赖 React 18、用单个 `<canvas>` 和 `requestAnimationFrame` 做 60fps 平滑插值；核心 API 只有 `data` 和 `value`，但可按需开启 momentum arrows、value overlay、time windows、orderbook stream、candlestick、多序列、loading/paused 等状态。适合需要“活”的实时数据 feed，又不想引入重型图表库的场景。 #[[React.js]] #[[Visualization]]
